# WhatCanYaDo

A local puzzle app for practicing TypeScript. Each puzzle page has a bug in its source. Fix the bug so the message reads Hello World.

The first puzzle starts unlocked. Solving a puzzle unlocks the next one. Progress is saved in this browser under the `localStorage` key `whatcanyado.progress`.

## Run

```sh
npm install
npm run dev
```

Open the URL Vite prints. The app is meant to stay on your machine.
